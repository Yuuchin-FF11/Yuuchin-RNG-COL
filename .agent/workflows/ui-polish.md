# UI研磨ワークフロー (Premium UI/UX)

このワークフローは、`premium_ui_ux` スキルを活用して、ウェブサイトの見た目を「プロ級」に引き上げます。

## 手順

1. **デザインスキャン**:
   - 現在の `index.html` と `styles.css` を分析し、改善の余地がある箇所を特定します。
2. **コンポーネントの提案**:
   - ガラス質感のカード、動的なグラデーション背景、マイクロインタラクションの適用案を提示します。
3. **安全な実装**:
   - 元のスタイルを破壊しないよう、CSS変数を活用してモダンなスタイルを上書きします。
4. **検証**:
   - ブラウザツールでアニメーションやレスポンシブ表示が正しいか確認します。

## 使用例
- `/ui-polish メインセクションをガラス質感のデザインに変更して`
- `/ui-polish ボタンに高級感のあるホバーエフェクトを追加して`
