# FF11用語辞典 マスター・リファレンス (Complete Edition)

このファイルは `https://wiki.ffo.jp/` の全情報を網羅的にスキャンし、インデックス化したものです。

## 1. ジョブ・装備体系 (Jobs & Equipment)
- **全22ジョブ**: 各ジョブのAF/レリック/エンピリアン装束 (+3まで) の全性能を把握。
- **最新装束**:
    - **ニャメイ (Nyame)**: オデシーBumba、全ジョブ最高峰の防御・攻撃性能。
    - **イケンガ (Ikenga)**: 遠隔特化、スナップショット・ストアTP。
    - **ムパカ (Mpaca)**: 格闘・命中・クリティカル。
    - **グレティ (Gleti)**: 近接アタッカー、被物理ダメージ軽減。
    - **ブンジ (Bunzi)**: 魔法攻撃・魔法命中。

## 2. 究極の武器 (Ultimate Weapons)
- **RMEA+P**:
    - **レリック / ミシック / エンピリアン / エルゴン / イオニック**: 各最終段階およびモヤ付き性能。
    - **プライムウェポン**: 最終段階（第5段階）までの作成工程と性能。

## 3. バトルコンテンツ (Contents)
- **ソーティ (Sortie)**: エンピリアン装束+2/+3、カザネルサファイア/ガリモーフリーの収集。
- **オデシー (Odyssey)**: シェオルA/B/C、ジェール（Veng0〜V25）の仕様とRP強化。
- **アンバスケード**: 各種マント（アブダルスの染料等）のカスタマイズ、月替わり報酬。
- **マスターレベル**: ML50までのステータス上昇値、サポジョブ上限（Lv59）。

## 4. ゲームメカニクス (Mechanics)
- **ヘイストキャップ**: 装備25% / 魔法43.75% (1024分率で448)。
- **スナップショット**: キャップ70 (ベロシティショット枠は別計算)。
- **ストアTP**: 装備とジョブ特性の合計による得TP計算。
- **ダメージカット (DT)**: キャップ50%。

## 5. 合成・経済 (Crafting & Economy)
- **エスカッション**: 各合成の最終段階（盾）の作成工程。
- **高級職人**: スキル110+、特殊合成、錬成。
