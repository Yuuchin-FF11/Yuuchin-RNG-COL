# Safety Sandbox & Compliance Skill

## Description
このスキルは、生成されたコードや実行コマンドが安全基準を満たしているか、また隔離された環境（サンドボックス）での実行に適しているかを検証します。

## Instructions
1. **実行前検証**: ファイル削除、ネットワークアクセス、システム設定の変更を伴うコマンドに対し、警告と代替案を提示します。
2. **サンドボックス適合性**: コードがコンテナ化された環境や制限されたディレクトリ内でのみ動作するよう、パス参照を正規化します。
3. **規約遵守（Compliance）**: セキュリティのベストプラクティス（OWASP等）に基づき、潜在的な脆弱性を自動スキャンします。

## Usage
- 「このコマンドを実行しても安全か確認して」
- 「生成したコードのセキュリティスキャンを実行して」
