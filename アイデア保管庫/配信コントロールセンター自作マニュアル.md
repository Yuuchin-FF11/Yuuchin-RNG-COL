# APIキー完全不要！配信コントロールセンター（翻訳＆読み上げコメビュ）自作マニュアル

このマニュアルは、現在配信で使用されている「APIキー不要で無限にチャットを取得し、自動翻訳、音声読み上げ、お上品フィルター、各種辞書機能」などを備えた、プロ仕様の配信コントロールセンターを自作するための完全ガイドです。

---

### ・配信・AI初心者向け：このツールで「できること」と「メリット」

「1. これ1つで、コメント取得、翻訳、読み上げ、NGワード対策がすべて完結します」
・これまでは、コメントを表示するソフト、翻訳するソフト、読み上げるソフトを別々に起動して連携させる必要があり、設定が非常に複雑でした。このツールなら、配信画面に必要なすべての便利機能が1つの画面でまとめて管理・操作できます。

「2. 荒らしや不適切な言葉（NGワード）を自動でフィルタリングして、配信の安全を守ります」
・配信中にリスナーが暴言やBAN対象になるような不適切な言葉を打った場合、ツールが自動でそれを検知し、お上品な可愛いマークに伏字化（フィルタリング）して表示します。

「3. 配信の聞き間違いや、固有名詞の読み間違いを自分で修正して学習させることができます」
・マイクが「派遣」を「覇権」と聞き間違えて誤翻訳してしまうような現象を自動で正しい言葉に直す「マイク修正辞書」や、リスナーの名前や難しい漢字を合成音声に正しく喋らせる「読み上げ辞書」を、画面から簡単に登録してツールを賢く成長させることができます。

---

## 1. このツールで実現できる全機能
- 【APIキー不要のチャット自動取得】: Edgeの特殊な起動オプションを利用してYouTubeのチャット要素に直接アクセス（スクレイピング）するため、APIキーなしで無限にチャットを取得可能。
- 【配信者マイク音声のリアルタイム英訳字幕】: マイクに向かって日本語で喋るだけで、自動で英訳されてOBS画面へ流れます。
- 【日本語コメントの自動英訳（海外コメ専用フィルター）】: リスナーの日本語コメントを自動で英訳してOBSに表示し、配信をグローバル化します。
- 【お上品フィルター（NGワード機能）】: BAN対象になるような不適切な言葉を自動で「🐾」などの伏字にします。
- 【音声読み上げ ＆ 読み上げ辞書】: 届いたチャットを合成音声（ななみちゃん等）で自動読み上げ。特定の単語の正しい読み方を登録・保存できます。
- 【マイク誤認識修正辞書】: マイク認識時の聞き間違い（例：「派遣」を「覇権」）を、正しいフレーズに自動で置換します。
- 【OBSオーバーレイ連携】: ディープネイビーとゴールドを基調とした、上品なガラスモーフィズムの字幕表示。

---

## 2. システム構成と必要なファイル
このシステムは、以下の４つのファイルで動作します。

1. 【server.ps1】（ローカルHTTPサーバー）: OBSやブラウザから安全にファイルを読み込むための簡易サーバープログラム。
2. 【起動用バッチ（コメビュ版起動.bat）】: 二重起動を自動防止し、CORS（セキュリティ制限）を無効化したEdgeブラウザで管理画面を開くプログラム。
3. 【コントロールパネル（admin.html）】: すべての機能設定、辞書管理、ログ表示、マイク入力を制御する管理画面。
4. 【オーバーレイ画面（overlay.html）】: OBSに透過して重ねるための字幕表示用画面。

## 3. 各ファイルのコードと作成手順

任意のフォルダ（例：「配信コントロールセンター」）をPC内に作成し、その中に以下の４つのファイルをテキストエディタで作成して保存します。

### ① ローカルサーバー「server.ps1」
以下のPowerShellスクリプトを、ファイル名「server.ps1」として保存してください。

```powershell
# ローカルでHTMLファイルを配信するための簡易HTTPサーバー
$port = 8080
$listener = New-Object System.Net.HttpListener
$listener.Prefixes.Add("http://localhost:$port/")
try {
    $listener.Start()
    Write-Host "ローカルサーバーがポート $port で起動しました..." -ForegroundColor Green
    while ($listener.IsListening) {
        $context = $listener.GetContext()
        $request = $context.Request
        $response = $context.Response
        
        # HEADリクエスト対策
        if ($request.HttpMethod -eq "HEAD") {
            $response.StatusCode = 200
            $response.Close()
            continue
        }

        # パスからファイルを特定
        $path = $request.Url.LocalPath
        if ($path -eq "/") { $path = "/admin.html" }
        $filePath = Join-Path $PSScriptRoot $path

        if (Test-Path $filePath -PathType Leaf) {
            $bytes = [System.IO.File]::ReadAllBytes($filePath)
            $response.ContentLength64 = $bytes.Length
            
            # MIMEタイプの設定
            if ($path.EndsWith(".html")) { $response.ContentType = "text/html; charset=utf-8" }
            elseif ($path.EndsWith(".css")) { $response.ContentType = "text/css; charset=utf-8" }
            elseif ($path.EndsWith(".js")) { $response.ContentType = "application/javascript; charset=utf-8" }
            
            $response.OutputStream.Write($bytes, 0, $bytes.Length)
        } else {
            $response.StatusCode = 404
        }
        $response.Close()
    }
} finally {
    $listener.Close()
}
```

### ② 起動用バッチ「コメビュ版起動.bat」
以下のバッチファイルを、ファイル名「コメビュ版起動.bat」として保存してください。
※二重起動によるポート競合を防ぐため、古いポート8080のプロセスを自動タスクキルする機能が含まれています。

```batch
@echo off
chcp 65001 > nul
title 配信コントロールセンター起動ランチャー

echo ===================================================
echo   古いプロセスの確認 ＆ ポート8080の大掃除を実行中...
echo ===================================================
for /f "tokens=5" %%a in ('netstat -ano ^| findstr :8080') do (
    taskkill /F /PID %%a 2>nul
)

echo ===================================================
echo   ローカルサーバーを起動中...
echo ===================================================
start /b powershell -ExecutionPolicy Bypass -File "%~dp0server.ps1"
timeout /t 2 >nul

echo ===================================================
echo   CORS無効化オプションで Microsoft Edge を起動中...
echo ===================================================
start msedge.exe --app="http://localhost:8080/admin.html" --disable-web-security --user-data-dir="%~dp0edge_profile"

exit
```

        // --- 4. フィルター ＆ 辞書処理 ---
        function applyNsfwFilter(text) {
            const nsfwWords = document.getElementById('nsfw-words').value.split(',');
            let result = text;
            nsfwWords.forEach(word => {
                const trimmed = word.trim();
                if (trimmed) {
                    const regex = new RegExp(trimmed, 'gi');
                    result = result.replace(regex, '🐾'.repeat(trimmed.length));
                }
            });
            return result;
        }

        function applyReadDict(text) {
            let result = text;
            const sortedDict = [...dictList].sort((a, b) => b.word.length - a.word.length);
            sortedDict.forEach(item => {
                result = result.replace(new RegExp(item.word, 'g'), item.reading);
            });
            return result;
        }

        function applyMicDict(text) {
            let result = text;
            const sortedMicDict = [...micDictList].sort((a, b) => b.wrong.length - a.wrong.length);
            sortedMicDict.forEach(item => {
                result = result.replace(new RegExp(item.wrong, 'g'), item.correct);
            });
            return result;
        }

        // --- 5. 音声合成（読み上げ） ---
        function speakText(text, lang) {
            if ('speechSynthesis' in window) {
                window.speechSynthesis.cancel();
                const utterance = new SpeechSynthesisUtterance(text);
                utterance.lang = lang;
                
                const voices = window.speechSynthesis.getVoices();
                const targetVoice = voices.find(v => v.lang.startsWith(lang.split('-')[0]));
                if (targetVoice) utterance.voice = targetVoice;

                window.speechSynthesis.speak(utterance);
            }
        }

        // --- 6. OBSオーバーレイへのデータ送信 ---
        function sendToOverlay(jaText, enText) {
            const messageData = {
                id: Date.now(),
                ja: jaText,
                en: enText
            };
            localStorage.setItem('translation_message', JSON.stringify(messageData));
        }

        // ログ追加
        function addLog(msg) {
            const p = document.createElement('p');
            p.style.margin = '3px 0';
            p.innerText = msg;
            logList.appendChild(p);
            logList.scrollTop = logList.scrollHeight;
        }

        // --- 辞書UI制御 ---
        document.getElementById('btn-add-dict').onclick = () => {
            const word = document.getElementById('dict-word').value.trim();
            const reading = document.getElementById('dict-reading').value.trim();
            if (word && reading) {
                dictList.push({ word, reading });
                localStorage.setItem('read_dict', JSON.stringify(dictList));
                renderDicts();
            }
        };

        document.getElementById('btn-add-mic-dict').onclick = () => {
            const wrong = document.getElementById('mic-wrong').value.trim();
            const correct = document.getElementById('mic-correct').value.trim();
            if (wrong && correct) {
                micDictList.push({ wrong, correct });
                localStorage.setItem('mic_dict', JSON.stringify(micDictList));
                renderMicDicts();
            }
        };

        function renderDicts() {
            const container = document.getElementById('dict-list');
            container.innerHTML = '';
            dictList.forEach((item, index) => {
                const div = document.createElement('div');
                div.innerHTML = `${item.word} ➔ ${item.reading} <button class="btn btn-danger" style="padding:2px 5px; font-size:10px;" onclick="deleteDict(${index})">削除</button>`;
                container.appendChild(div);
            });
        }

        function renderMicDicts() {
            const container = document.getElementById('mic-dict-list');
            container.innerHTML = '';
            micDictList.forEach((item, index) => {
                const div = document.createElement('div');
                div.innerHTML = `${item.wrong} ➔ ${item.correct} <button class="btn btn-danger" style="padding:2px 5px; font-size:10px;" onclick="deleteMicDict(${index})">削除</button>`;
                container.appendChild(div);
            });
        }

        window.deleteDict = (index) => {
            dictList.splice(index, 1);
            localStorage.setItem('read_dict', JSON.stringify(dictList));
            renderDicts();
        };

        window.deleteMicDict = (index) => {
            micDictList.splice(index, 1);
            localStorage.setItem('mic_dict', JSON.stringify(micDictList));
            renderMicDicts();
        };

        renderDicts();
        renderMicDicts();
    </script>
</body>
</html>

## 4. 使い方（ツールの起動とOBS設定）

1. <b>ツールの起動</b>
   - 作成した「コメビュ版起動.bat」をダブルクリックして起動します。
   - 自動的にポート8080でローカルサーバーが起動し、CORS無効化された状態でMicrosoft Edgeが開き、コントロールパネル（admin.html）が表示されます。
2. <b>YouTube配信への接続</b>
   - 配信URL（例: `https://www.youtube.com/watch?v=...`）を入力欄に貼り付け、「コメビュに接続」ボタンを押します。
   - 下部のステータスに「接続完了！」と表示されれば成功です。
3. <b>OBSへの字幕画面の取り込み</b>
   - OBSのソースパネルの「＋」から「ブラウザ」を追加します。
   - URLに「`http://localhost:8080/overlay.html`」を入力します（ローカルサーバーから読み込むため、ローカルファイルのチェックは外したままでOKです）。
   - 幅「1280」、高さ「720」に設定します。
4. <b>マイク音声の配信テスト</b>
   - コントロールパネルの「マイク認識を開始する」を押し、マイクに向かって喋ると自動で英訳され、OBSの画面に字幕が表示されます。
