# プレミアム UI/UX デザインスキル

## このスキルの目的
Webツールや記事ページ、アプリの画面において、安っぽさを排除し、プロフェッショナルで高級感・透明感のあるデザイン（Glassmorphism、微細なアニメーション、適切な余白設計）を実装するための指針とリソースを提供する。

## 主なデザイン指針
1. 【Glassmorphism（すりガラス効果）】:
   - 背景のブラー効果（`backdrop-filter: blur(15px)`）と、半透明な白/黒（`rgba(255, 255, 255, 0.08)`）を組み合わせ、立体感とモダンさを両立する。
   - 繊細なボーダー（`border: 1px solid rgba(255, 255, 255, 0.15)`）で境界を際立たせる。
2. 【タイポグラフィとコントラスト】:
   - OS標準の粗いフォント指定を避け、洗練されたフォントファミリ（Inter, Outfit, 日本語ならNoto Sans JP等）を採用する。
   - 文字と背景のコントラスト比（WCAG基準）を意識し、暗い背景でも可読性を損なわない文字色（`#f1f5f9` や `#94a3b8` 等）を階層分けして使用する。
3. 【マイクロインタラクション】:
   - ボタンやカードのホバー時に、微細なY軸移動（`transform: translateY(-2px)`）やシャドウの変化をなめらか（`transition: 0.2s ease`）に付与する。
   - クリック時の沈み込みなど、触って気持ちいいフィードバックを設ける。
4. 【絵文字・装飾の禁止】:
   - 本プロジェクトの規律に従い、UI上に不要な絵文字（🐾等）は一切配置しない。アイコンが必要な場合はSVGアイコン等を使用する。

## 付属リソース
- `resources/templates.css` に基本的なGlassmorphismやグラデーションメッシュのCSSスニペットを格納。
