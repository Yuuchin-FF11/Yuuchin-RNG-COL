# Git & Workflow Automation Skill

## Description
このスキルは、Gitによるバージョン管理と、プロジェクトのワークフロー自動化を高度にサポートします。

## Instructions
1. **セマンティック・コミット**: 変更内容を分析し、`feat:` や `fix:` といった視認性の高いコミットメッセージを自動生成します。
2. **ブランチ管理**: タスクに基づいた適切なブランチ名の提案と、マージのリスク評価を行います。
3. **ワークフロー定義**: `.agent/workflows` 内の手順書を読み取り、定型作業を最短ステップで実行します。

## Benefits
- コミットの履歴がクリーンになり、後からの追跡が容易になります。
- 手動でのGit操作ミスを劇的に減らします。
