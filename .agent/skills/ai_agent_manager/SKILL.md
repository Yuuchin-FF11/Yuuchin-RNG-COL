# AI Agent Creator & Manager Skill

## Description
このスキルは、特定のドメイン（FF11、特定言語のコーディング、ドキュメンテーション等）に特化したカスタムAIエージェントの定義と運用をサポートします。

## Instructions
1. **エージェント定義の作成**: `agents/` ディレクトリ内に、役割、目標、制約事項を明記した定義ファイルを生成します。
2. **コンテキスト最適化**: エージェントが必要な情報のみを参照できるよう、コンテキストウィンドウの管理を最適化します。
3. **安全な自律性**: エージェントが実行するアクションに対して、常に「人間による最終確認（Human-in-the-loop）」のステップを組み込みます。

## Guidelines
- 新しいエージェントを作成する際は、既存のプロジェクトルール（`.agent/rules`等）を継承させます。
- エージェント間の連携が必要な場合、インターフェースを明確にします。
