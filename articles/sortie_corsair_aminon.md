# Aminon (Hard Mode) コルセア立ち回り (Sortie Hard Aminon Corsair Guide)

ソーティ（Sortie）の真の最難関ボスである**Aminon (Hard Mode / 強バージョン)**戦における、コルセア（COR）の極めて実戦的かつ具体的な立ち回りをまとめた専用攻略ページです。🐾

---

## 🧭 開幕・戦闘開始直前のロール回し

Aminonの部屋（BF内）に到着後、戦闘開始前に味方パーティへ付与するロールは以下の**2通りのパターン**が存在します。編成や戦術に応じて使い分けます。

| パターン | 使用するロールの組み合わせ | 主な目的・用途 |
| :--- | :--- | :--- |
| **パターンA** | **カオスロール ＋ タクティシャンロール** | 攻撃力（飛攻・攻撃力）を高めつつ、強力なリゲインでTPを確保する基本スタイル。 |
| **パターンB** | **マイザーロール ＋ タクティシャンロール** | WS使用時のTP消費を抑え（セーブTP）、タクティシャンのリゲインと合わせてWS回転率を極限まで高めるスタイル。 |

### 🔄 クルケッドカードを最大限に活かすロール回し手順

1.  **クルケッドカード**を使用し、1つ目のロール（例：カオスまたはマイザー）を回します。
2.  即座に**ランダムディール**を実行します。
3.  ランダムディールにより**クルケッドカード**がリセット（再使用可能に復活）していれば、2つ目のロール（タクティシャンロール）にもクルケッドカードを使用して回します。
    *   *※これにより、2つのロール双方にクルケッドカードの効果（ロール値の効果大幅アップ）を乗せる超強力な戦術支援が完成します！*🐾

## ⚔️ 戦闘開始後の立ち回りと削り

### 1. タクティとドローによる爆速TP確保
戦闘が開始されたら、以下の方法でTPを最速で蓄積します。
*   事前に付与した**タクティシャンロール**による自動リゲイン効果。
*   アビリティ**クイックドロー**を敵に撃ち込み、TPを能動的に素早く蓄積します。

### 2. サベッジブレードによる精密な削り
*   TPが溜まり次第、片手剣WS**サベッジブレード**を撃ち込んでAminonのHPを的確に削っていきます。
*   *※Aminonのギミック（属性WSのダメージ吸収など）の性質上、無属性・物理WSであるサベッジブレードによる削りが非常に安全かつ強力な主軸となります。*

## 🎯 赤魔道士との弱体魔法・クイックドロー連携

Aminon (Hard Mode)戦では、パーティの赤魔道士（RDM）が敵に付与した超重要弱体魔法の効果を、コルセアのクイックドローで「効果深度アップ（強化）」させることが極めて重要です。

赤魔道士が弱体魔法を入れたタイミングを見逃さず、対応するショットを即座に撃ち込みます。

### 🤝 弱体魔法と対応ショット一覧

| 赤魔道士の弱体魔法 | コルセアの対応ショット | 強化される弱体の効果 |
| :--- | :--- | :--- |
| 🔴 **ディア (Dia)** | ➡️ **ライトショット (Light Shot)** | 防御力ダウン効果の深度をさらに引き上げ、パーティ全体の物理ダメージを底上げします。 |
| 🔵 **パライズ (Paralyze)** | ➡️ **アイスショット (Ice Shot)** | 麻痺（パライズ）の発生確率と深度を引き上げ、敵の強力な手数を大幅に阻害します。 |

### ⚠️ クイックドロー支援時の絶対装備ルール
*   これらの弱体効果アップ（ショットによる支援）を実行する際は、**必ずエンピリアン足防具（ＬＡブーツ+3 / ラヌンブーツ+3等）を装備**してショットを撃ってください！
*   **エンピ足の超重要スペック**:
    *   「クイックドロー性能アップ（弱体効果深度+20%・効果時間延長）」という唯一無二のプロパティを宿しており、さらに高い魔法命中率（魔命）を併せ持っているため、Aminonの極めて高い魔回避を確実に貫通して弱体効果を極限まで高めることができます。🐾
