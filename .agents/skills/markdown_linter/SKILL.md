# マークダウン・構文チェッカースキル

このスキルは、執筆中のマークダウン記事内でのリスト箇条書き（中黒による表示崩れの防止）、見出しレベルの整合性、および空行不足によるテキストの連結バグを自動検証・修正するための手順を定義します。

## 使用方法

記事の変更（replace_file_contentやwrite_to_fileなど）を行う直前、またはコミット（git commit）を行う直前に、必ず検証スクリプト「scripts/lint_markdown.py」を実行して、編集対象のマークダウンファイルを検証します。

## 検証ルール

1. リストの箇条書きに全角中黒（・）が使用されていないかスキャンし、検出された場合は自動的に半角ハイフン（- ）に置換します。
2. 見出しタグ（#、##、###、####）の階層が、他のページと統一されているか（レベル5以上を使用していないかなど）を確認します。
3. 箇条書きリストと前後の段落の間に、適切な空行が確保されているかを確認し、表示崩れを防ぎます。
