# Web Scraping & Analysis Expert Skill

## Description
このスキルは、AIエージェント（Antigravity）が持つ強力な組み込みツール（`read_url_content` および `browser_subagent`）を駆使して、参考となるウェブサイトの情報を効率的かつ正確にスクレイピング（抽出）し、プロジェクトに活用するためのワークフローを提供します。
外部のMCPサーバーや追加のアドオンをインストールすることなく、ネイティブの機能で高速な情報収集を実現します。

## Integrated Tools & Capabilities
1. **read_url_content (高速静的スクレイピング)**: 
   - HTTPリクエストを通じてページのHTMLを瞬時にMarkdown形式に変換して取得します。
   - ブログ記事、Wikiデータ、公式ドキュメントなどの静的テキストの抽出に最適です。
2. **browser_subagent (動的・視覚的スクレイピング)**:
   - ブラウザを実際に立ち上げ、JavaScriptで動的に生成されるページや、ログインが必要なページ、複雑なUIの操作をエミュレートします。
   - スクリーンショットの撮影や、DOMツリーの解析、クリックやスクロールを伴う情報収集に最適です。

## Instructions
1. **対象サイトの選定と分析**: ユーザーから指定されたURL、または参考になりそうな「見本サイト」のURLを確認します。
2. **ツールの使い分け**:
   - テキストや基本的な構造だけが必要な場合は `read_url_content` を使用します。
   - UIの構造やデザイン、動的コンテンツを取得したい場合は `browser_subagent` を使用して解析します。
3. **データの抽出と加工**: 取得したMarkdownデータやDOM情報を解析し、必要な要素（テキスト、画像パス、CSS構造など）を抽出します。
4. **プロジェクトへの適用**: 抽出した情報を基に、Markdown記事の生成や、Glassmorphism等のデザインパターンを取り入れたHTML/CSSコードを生成します。

## Usage Examples
- "FF11 Wikiのコルセアのページをスクレイピングして、データを表にまとめて"
- "参考サイトのURLを渡すので、このサイトのUI構造を解析して、同じようなカードデザインを作って"
- "このブログの最新記事のテキストだけを高速で抽出して"
