# 安全・品質監査ワークフロー (Safety & Quality)

このワークフローは、`safety_sandbox` と `code_quality_expert` スキルを使用して、プロジェクトの健全性を保ちます。

## 手順

1. **セキュリィスキャン**:
   - 外部接続（MCP含む）や機密情報の露出をチェックします。
2. **コード品質チェック**:
   - 未使用のコード、パフォーマンスのボトルネック、冗長な記述を特定します。
3. **リスク評価レポート**:
   - 変更が必要な箇所をリスク度（高・中・低）に分けて報告します。
4. **自動リファクタリング**:
   - 安全が確認された項目に対し、最適なコードへの修正を提案・実行します。

## 運用上の注意
- **安全点検（リグレッションテスト）の義務化**: すべての変更（特にCSSやレイアウト）を行った後、他のページ（`article.html` や `index_en.html` など）に予期せぬ影響が出ていないか必ずスキャンすること。
- **自動Git操作**: 英語版への反映および安全点検が完了した後、一括で `git add / commit / push` を行うこと。
- **透明性の確保**: 作業完了報告時に「英語版の同期も、他ページへの影響がないことも確認済みだよ！」と必ずユーザーに伝えること。

## 使用例
- `/safety-audit MCPの接続設定が安全か再チェックして`
- `/safety-audit プロジェクト全体の速度最適化を行って`
