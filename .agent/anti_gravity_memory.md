## 4. コーディング ＆ スクリプティング技術
### 【ミス内容】
* **PowerShellスクリプトの文字コード文字化け**：全角日本語を含む PowerShell スクリプトを実行した際、文字コードの不一致によって文字化けが生じ、構文解析エラー（UnexpectedToken）が発生した。
* **HTML/CSSのフレックスレイアウト崩れ**：aタグに対して直接 `flex: 1` を設定した結果、その直後にある New バッジが押し出されて改行落ちするレイアウト崩れを引き起こした。

### 【再発防止策】
* **PowerShellでの全角文字の完全排除**：PowerShellスクリプトを使用する際は、スクリプト内に全角日本語を1文字も含めず、ASCII文字（半角英数字）のみで動作するようにロジックを設計する（正規表現のワイルドカードやインデックス切り出し等を使用する）。
* **HTML/CSSのセーフレイアウト設計**：aタグとバッジなどのインライン要素が並ぶ場合は、それらを `div` 等のブロックで包んで `flex: 1` を指定し、親要素（liなど）には `display: flex; align-items: flex-start;` を設定するなど、レスポンシブ時に折り返しても崩れないセーフ設計を徹底する。

### 【ミス内容】
* ご主人様（ユーザー）が作成された下書きに対し、AIが憶測や不確かな知識で勝手に仕様を書き加えたり（改変）、ありもしない機能（三国のワープNPCから醴泉島へ飛ぶ等）をでっち上げたりした。

### 【再発防止策】
* **憶測・推測の完全排除**：ご主人様の下書きや指定した手順に対し、AIが勝手な知識で手順を「追加」「修正」「改変」することは絶対にしない。

* **自分の過去の出力を認識する**：過去に自分が提案・記述した内容を明確に区別し、ご主人様が書いていない言葉に対して疑問を持たれた場合は、自分が勝手に書いた表現であることを素直に認めて謝罪し、ご主人様の元の意図・記述を基準として修正する。
* **疑問点は勝手に補完せず確認する**：分からない手順や言葉がある場合、絶対に自分で勝手に調べてでっち上げず、必ずその場でご主人様に確認する。
* **役割の徹底**：AIの役割は「ご主人様が書かれた文章を読みやすく整理・装飾する（見栄えやフォーマットを整える）」だけであり、内容自体の改変や勝手な仕様の追加は絶対に行わない。
* **「問題ありません」と報告する前の徹底的な自己検閲**：一度修正したファイルや、全体確認を指示されたファイルについて、少しでも不審な記述（特に括弧書きでの補足説明など、AIが勝手に追加しやすい部分）がないか、一言一句をチェックする。
* **英語名詞の安易なカタカナ直訳による日本語アビリティ名の作成禁止**：英語のアビリティ名やアイテム名（例: Tactician's Roll）を安易にカタカナ直訳して日本語版に実在しない名称（例: タクティシャンロール）を絶対に作らない。日本語版の正式アビリティ名は「タクティックロール」であり、これをご主人様が書かれている場合は絶対に勝手に書き換えない。
