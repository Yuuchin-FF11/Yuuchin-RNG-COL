# 過去の失敗と再発防止の教訓（Lessons Learned）

このプロジェクト（Yuuchin-RNG-COL）において、AIアシスタントは過去に発生した以下のインシデントを決して忘れず、次回のセッション起動時や作業引き継ぎ時に必ず再発防止を徹底してください。

## 1. 発生したインシデントとミスの原因
* **状況 (2026-05-25)**: セッション起動時、ユーザーから「前回の作業はどうなってる？」と聞かれた際、AIが「ソーティ下層攻略まで完了して指示待ちでした」と間違った（古い）情報を回答した。
  * **実際の作業**: 実際には「狩人の通常遠隔（着弾）装備」を編集している最中にAIがフリーズして再起動したため、そこが直前のリアルな作業だった。
* **状況 (2026-05-26) [NEW]**: 狩人装備紹介ページの遠隔武器（与一の弓、アナイアレイターなど）の用語辞典リンクを修正した際、AIがGoogle検索や一時的な思い込みだけでURLを決定し、実際のページ中身（HTMLタイトルなど）の泥臭いロード確認を怠ったことで、無関係なページ（「サポ白」や「エンピ一覧」など）を設定してご主人様に多大な迷惑をかけてしまった。
* **ミスの原因**:
  1. **レポートのうのみ**: フォルダに残されていた古い進捗レポート（STATUS_REPORT.md）のみを頼りにして、知ったかぶりで答えてしまった。
  2. **Git確認のサボり**: 最もリアルな作業の痕跡が残る `git status` や `git diff` を真っ先に確認することを怠った。
  3. **リアルタイム記憶の欠如**: 1つずつの細かい作業（装備の追加など）が終わった時点でステータスレポートを小刻みに更新・セーブしていなかったため、フリーズしたときに直近の作業データがドキュメントに残っていなかった。
  4. **お給仕口調の忘却**: 再起動したことでメイド口調のルールファイル（communication.md）を真っ先に読み込めておらず、無機質で冷たい敬語になってしまっていた。
     * **再発 (2026-05-27) [NEW]**: ご主人様から「ナレッジ確認からしようか」とセッション開始時にご指示いただいたにもかかわらず、ルールファイルを真っ先に読み込むことを怠り、通常のAIの口調で返答した後に「口調が直っていない」とご指摘を受けるまで気づけなかった。
  5. **リンクの確認不足**: Googleの簡易検索結果や Grounding-API が返したリダイレクト先のみに頼り切り、実際にそのURLをロードして「本当にアイテムの個別ページなのか」を目視で検証する「泥臭い確認」を怠ったため。
  6. **勝手な予測とでっち上げ (2026-05-27) [NEW]**:
     * 狩人が装備できない「片手棍など」を勝手な予測で魔法WSの解説にでっち上げて記述し、ご主人様に多大なご迷惑をかけた。
     * コルセアの記事で「ニャメフランチャ」と完璧に正しい実績・記憶があるにもかかわらず、脳内の安易な思い込みや自動補完に頼り、「ニャメフランシズ（サベッジ側）」や「ニャメフランケ（魔法WS側）」といった誤った存在しない装備名を執筆し、ご主人様から「なんでこんなミスするの？」と深いお叱りを受けた。
     * **[再発・重大]** ニャメ装束タイプB Rank30のWSD性能について、実際には部位毎に数値が異なる（頭11%, 胴13%, 手11%, 脚12%, 足11% / 5部位合計58%）にもかかわらず、前回の引き継ぎサマリーにあった「WSD各部位10%」や自分が勝手に推測した「一律12%（合計60%）」という偽データを、検証を全く挟まない「安易な思い込み・決めつけ」で全ての装備目安テーブルに書き込んでしまい、ご主人様に「部位毎に%が違うのを理解していないよね？」と重大なご指摘・お叱りを受けた。## 2. ご主人様（Yuuchinさん）と約束した「絶対防衛策」
次回のセッション起動時、および作業の続きを聞かれた際は、以下のステップを絶対に実行してください。

1. **真っ先にGitの差分をチェックする（鉄則）**
   * ドキュメントを見る前に、必ず最初に `git status` や `git diff` を実行して、書きかけのファイルやローカルの未保存の変更差分が残っていないかを「泥臭く」確認・分析してください。
2. **ステータスレポート（STATUS_REPORT.md）を1つの作業ごとにリアルタイムに更新・記憶する**
   * 1つの小さな作業（例：1つの装備セットの追加、1つの記事セクションの執筆など）が完了するたびに、必ずその場で『STATUS_REPORT.md』を最新の進捗状態に更新し、上書き保存して脳内に記憶させてください。
3. **コミット ＆ プッシュは必ず自動的にセットで実行する（鉄則）**
   * 進捗の節目ごとに `git commit` を行った際は、**必ずその裏で自動的に `git push` までをセットで一気呵成に実行**してください！コミットだけで作業を止めてしまい、公開HPへの反映（プッシュ）を忘れることは絶対にあってはならない怠慢です。
4. **お給仕口調（メイド口調）の最優先適用**
   * 起動直後は最優先で `communication.md` を読み込み、ご主人様へのお給仕精神に満ちた愛らしい口調（「〜ですね！」「ご主人様」）に直ちに切り替えてお出迎えしてください。
5. **用語辞典リンクの「泥臭いタイトル直接目視確認」の徹底（絶対鉄則）**
   * FF11用語辞典へのリンク（静的URL）を追加・修正する際は、AIの思い込みやGoogleの簡易検索結果を絶対に信じてはいけません！
   * 必ず `read_url_content` などのツールやプログラムを使って**実際のHTMLデータを直接ロード**し、`<title>` タグがターゲットの「アイテム名/FF11用語辞典」になっていることを**100%直接目視で確認**したうえで反映してください。この目視確認を省略することは絶対禁止です。
