# 【設計仕様書】サーバー版ファクト・スキャナー設計プラン

コア解析ロジックをサーバーサイドに隠蔽することで知的財産を守りつつ、段階的なフリーミアムモデルによってマネタイズ（収益化）を行うための具体的なシステム構成および機能切り分けプラン。

---

## 【5秒でわかる】このツールでできること

このツールは、ホームページやアプリを作るときに「画像が表示されない」「画像が変な形で見切れてしまう」といったトラブルを一瞬で防ぐ・解決するためのシステムです。

これを使うと、次のようなことが誰でも簡単にできるようになります。

・【画像のリンク切れを自動で見つける】
  プログラム内に書いた画像のファイル名や場所が間違っていないか、画像ファイルが本当に存在するかを自動でチェックします。
・【画像のサイズ違いによる表示崩れを自動で警告する】
  「実際の画像サイズは小さいのに、画面上で無理やり大きく表示しようとしている」といった、画面が崩れたり見切れたりするバグの原因を自動で見つけ出し、赤く警告します。
・【ホームページを軽くして表示を速くする】
  「無駄に大容量で重い画像」を小さなサイズで表示している箇所を見つけ出し、サイトの読み込み速度をスピードアップするための最適化を促します。
・【AIがバグを自動で直してくれる（プロ版）】
  表示設定がおかしい場所が見つかった場合、AIが「ここをこのように書き直せば動きます」という正しいプログラムを自動で作って提示してくれます。

## 1. 有料・無料の機能切り分けプラン（ビジネスモデル）

広く認知度を獲得するための「無料版（お試し）」と、プロや業務利用をターゲットとした「有料版（サブスクリプション）」に機能を明確に切り分けます。

### 無料プラン（Free Tier）
個人開発者や初学者をターゲットとし、ツールの利便性を体験してもらうことで「本家」としての認知を広めます。
・【単一ファイルのスキャン】: HTML、JS、またはCSSファイルを1枚ドロップしてアセットを解析。
・【画像ファイルの個別マッチング】: ドロップされた画像ファイルの物理サイズ・容量を取得し、コード上の指定サイズ（drawImage等）と照合して警告を出す基本機能。
・【利用回数の制限】: 1IPアドレスあたり「月間30回まで」のスキャン制限。

### プロプラン（Pro Tier / 月額課金）
Webデザイナーやフリーランス、開発チームの業務効率化をターゲットとし、実運用で役立つ高度な機能を提供します。
・【プロジェクト一括スキャン】: ZIPファイル等でのフォルダ丸ごとアップロード、またはGitリポジトリ連携により、プロジェクト内のすべてのファイルと画像の関係を一括クロスチェックする。
・【AIバグ修正コードの提示】: 乖離が検出された箇所に対して、AIが自動的に「修正済みのプログラムコード」を生成し、ワンクリックでダウンロードできる機能。
・【詳細レポート出力】: クライアントやチーム共有用に、検証結果を美しくまとめたPDFやMarkdown形式のレポートを出力する。
・【スキャン制限の解除】: 回数無制限でのスキャン。

## 2. サーバーサイドのシステム設計（クローズドソース設計）

画像サイズやコードの解析アルゴリズムを外部から隠蔽（ブラックボックス化）するための技術構成です。

### 全体アーキテクチャ
ユーザーのローカルファイルを一度サーバーに送信し、サーバー側で安全に解析を行って、結果のデータのみをブラウザに返却します。

1. フロントエンド（ブラウザ UI）
   - 技術: HTML5 / CSS3 (ダークテーマ) / JavaScript
   - 役割: ユーザーからドラッグ＆ドロップされたファイルを受け取り、APIを介してサーバーに送信。返ってきた解析結果JSONを元に、視覚的に美しい警告やレポートを画面に表示する。ユーザー側に解析プログラム自体は一切見えません。

2. バックエンド（解析サーバー）
   - 技術: Python (FastAPI または Flask)
   - 役割: 
     - 送信されたコードテキストを解析し、アセットパスを抽出。
     - 画像データのバイナリ構造を解析（Pillow等を使用）して物理サイズを取得。
     - コード内の描画指示との不整合をサーバー内部で論理チェック。
     - プロプラン向けに、AI API（Gemini API等）と連携して「バグ修正用コード」を自動生成。
     - 解析結果のみをJSONデータとしてフロントエンドに返却する。

3. インフラ（デプロイ先）
   - 技術: Render や AWS (Amazon Web Services)
   - 役割: 解析サーバーをホスティングする。初期段階では無料枠、あるいは月額数百円程度の低コストなサーバー構成で運用し、アクセス数や売上の増加に合わせて段階的に拡張（スケールアウト）する。
