# マルチデバイス・レイアウトチェッカー (Responsive Layout Checker)

## 概要
CSSやHTMLを修正・追加した際に、スマホ（狭い画面）やタブレット、PCそれぞれの画面サイズで「表示崩れ」や「要素の被り（ヘッダーとタイトルの重複など）」が起きないかを、ユーザーに確認される前にAI自身が論理的に検証し、未然に防ぐスキルです。

## 発動条件
- CSS（`styles.css` など）のレイアウトに関するプロパティ（`height`, `padding`, `margin`, `position`, `flex`, `grid` など）を変更したとき。
- ユーザーから「レイアウトが崩れていないか確認して」と指示されたとき。

## アクション内容
1. 変更したCSSのクラスやIDが影響を与えるHTML要素を特定する。
2. 以下の3つのビューポート（画面サイズ）のシナリオを頭の中でシミュレーションする。
   - **モバイル (Mobile)**: 幅 375px / 高さ 667px 程度（要素が縦積みになり、高さが伸びるケース）
   - **タブレット (Tablet)**: 幅 768px / 高さ 1024px 程度
   - **デスクトップ (Desktop)**: 幅 1200px〜 / 高さ 800px〜
3. 特に以下の「よくあるバグ」に該当しないかを検証する。
   - `height: 100vh` と `align-items: center` の組み合わせによる、コンテンツはみ出し（上下のクリッピング）。
   - 固定ヘッダー（`position: fixed`）の高さによる、アンカーリンク移動時のコンテンツ上部隠れ。
   - 画面幅を超過する要素（`width: 100vw` や巨大な画像）による意図しない横スクロールの発生。
4. 問題が予想される場合は、自ら `min-height` への修正や `scroll-padding-top` の追加などを行い、修正案を適用する。
5. 検証と修正が完了したのち、自動コミット＆プッシュを実行し、「スマホ・PCの両方の画面サイズで表示が崩れないかチェックして、修正しておいたよ！」と報告する。
