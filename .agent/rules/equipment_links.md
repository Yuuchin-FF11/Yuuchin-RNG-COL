# 装備品リンク生成ルール (Equipment Links Rules)

このプロジェクト（Yuuchin-RNG-COL）において、FF11用語辞典（wiki.ffo.jp）への装備品リンクを生成または挿入する際は、以下の絶対ルールを遵守してください。

## 1. 100%正確な「公式静的URL」の解読と適用の徹底（絶対ルール）
* **背景**: FF11用語辞典（wiki.ffo.jp）の検索CGI（`wiki.cgi`）は、JavaScriptの `encodeURIComponent` が生成する **UTF-8エンコードされたクエリを受け取ると、サーバーエラー（500 Internal Server Error）を返してしまう致命的な仕様制限**があります。そのため、ブラウザ上での動的CGIリンクは絶対に使用しないでください（ユーザーの画面で500エラーになります）。
* **絶対的な方法**: 必ず、正しいNQ/HQなどの区別を検証した**「公式の静的URL（`html/○○.html`または`html_2006/○○.html`）」**をマッピングして使用してください。
* **ミスの防ぎ方**: AIによる思い込みでの静的URLの判定はミス（ズレ）が非常に多いため、Google検索の結果（Google Groundingなどのリダイレクト機能）を介して、公式用語辞典の「本物の実URL（リダイレクト先の最終的な静的URL）」をプログラム（PowerShell等）で機械的に解決・特定してから登録してください。

## 2. 自動リンクエンジンの実装ルール
* HTMLテンプレート（`article.html` や `article_en.html`）内の自動リンク処理では、CGIに飛ばすのではなく、静的な `linkMap` の値（`html/○○.html`）をそのまま `href` に設定するロジックを維持・継承してください。
* 英語ページ（`article_en.html`）においても、`linkMap` の英語のキーに対して、上記の方法で特定された**完璧に正しい日本語版の公式静的URL**をマッピングしてください。

## 3. 装備品表記の共通仕様ルール (NEW)
* **ニャメ装束の表記**: 装備紹介ページや記事でニャメ装束（ニャメメイル、ニャメガントレなど）を記載する際は、必ず末尾に `（ランク３０）` と記載してください。
  * 例: `ニャメメイル（ランク３０）`、`ニャメガントレ（ランク３０）`
  * 英語版では、英語の表記ルールに沿って `(Rank 30)` と記載してください。（例: `Nyame Mail (Rank 30)`）
