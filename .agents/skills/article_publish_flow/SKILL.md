# 記事公開フロースキル

## このスキルの目的

記事が35本・日英ペアという規模になっており、公開フローの抜け漏れ（リンク紐付け忘れ、更新履歴の未記載、英語版の未反映など）を防ぐための標準手順を定める。

---

## 記事ファイルの構成ルール

### ファイル配置場所

すべての記事マークダウンファイルは `記事/` ディレクトリに格納する。

### 命名規則

日本語版と英語版はファイル名の末尾 `_en` で区別する：

- 日本語版：`記事/corsair_equip.md`
- 英語版　：`記事/corsair_equip_en.md`

新規記事を作成する場合は必ず日英ペアで用意する。英語版の内容が未完成の場合でも、ファイル自体は作成しておく。

---

## 記事公開の標準フロー（全5ステップ）

### Step 1：記事ファイルの作成・更新

ゆうさんが書かれた下書きを元に、`記事/` 配下のマークダウンファイルを作成または更新する。

AIの役割：
- 文章の読みやすさ・フォーマットの整理
- 見出し階層の統一（h1〜h4まで）
- 中黒（・）を使ったリストが崩れないかの確認

やってはいけないこと：
- ゆうさんが書いていない仕様・装備情報・手順を勝手に追加しない
- 英語名詞を安易にカタカナ変換してアビリティ名・装備名を作らない

### Step 2：FF11用語の検証（ffxi_validatorスキル連携）

記事内の装備名・アビリティ名・WSなどの固有名詞が実在するかを確認する。

```powershell
# 08_ホームページ検証ツール/scripts/validate_terms.py が存在する場合
python 08_ホームページ検証ツール\scripts\validate_terms.py 記事\<対象ファイル名>.md
```

実在が不確かな固有名詞は wiki.ffo.jp で手動確認する。

### Step 3：HTMLタグ・リンクの自動検証

記事公開後に `index.html` や `article.html` を修正した場合は、必ず以下のスクリプトを実行してタグ崩れ・リンク切れを検出する：

```powershell
# HTMLタグ整合性チェック
powershell -File 08_ホームページ検証ツール\スクリプト\dev_toolkit.ps1 html

# 記事内部リンクの存在チェック
powershell -File 08_ホームページ検証ツール\スクリプト\dev_toolkit.ps1 links

# link_map.js のwiki.ffo.jpリンク全件チェック（時間がかかるので装備追加時のみ）
powershell -File 08_ホームページ検証ツール\スクリプト\check_links.ps1
```

いずれかでエラーが出た場合はコミット禁止。修正してから再実行する。

### Step 4：更新履歴の記載（必須）

`記事/更新履歴.json` に新しいエントリを先頭に追記する。

フォーマット（既存エントリを参考に）：
```json
{
  "date": "2026.MM.DD",
  "file": "記事/ファイル名.md",
  "msgJa": "日本語での変更内容（読者向けの一文）",
  "msgEn": "English summary of the change",
  "isNew": true
}
```

- 新規公開記事 → `"isNew": true`
- 既存記事の更新 → `"isNew": false`
- HPファイル全体の修正（記事なし）→ `"file": ""`

### Step 5：git_deploy_guardスキルを実行してデプロイ

git_deploy_guard スキルのチェックリストを全項目クリアしてから `git push` する。

特に以下の2点を必ず確認する：

1. 新規記事の場合、`index.html` と `index_en.html` のナビゲーション・What's Newセクションに記事へのリンクが追加されているか
2. 日本語版を更新した場合、対応する `_en.md` ファイルも同様に更新されているか

---

## 記事とHPファイルの対応関係

記事は `article.html`（日本語）または `article_en.html`（英語）でレンダリングされ、URLパラメータ `?file=記事/xxx.md` で読み込まれる。

新規記事をナビゲーションに追加する場合は以下の2ファイルを編集する：
- `index.html` → 日本語メニューとWhat's New
- `index_en.html` → 英語メニューとWhat's New

---

## よくある抜け漏れパターン（過去の教訓）

- 日本語版を更新して英語版の更新を忘れる
- `更新履歴.json` への追記を忘れる
- `index.html` には追加したが `index_en.html` に追加し忘れる
- 記事ファイルを作っただけでナビゲーションのリンク紐付けを忘れる
- 下書き・検証用などの文言が記事タイトルや本文に残ったままデプロイする
