YouTube API キーの無料取得手順（最初の一度だけ必要です）

  1. Google Cloud Console にご自身のGoogleアカウントでログインします。
  2. 画面上のプロジェクト選択から「新しいプロジェクト」を作成します（名前は適当で構いません）。
  3. 左側メニューの「APIとサービス」＞「ライブラリ」を開き、検索窓に「YouTube」と入力して、YouTube Data API v3 を有効化（Enable）します。
  4. 有効化後、左メニューの「認証情報（Credentials）」を開き、画面上の「＋認証情報を作成」から「APIキー」を選択します。
  5. 生成された「AIzaSy...」から始まるAPIキーをコピーし、上の設定フォームに貼り付けて保存してください。

※APIキーは完全に無料の範囲内で稼働します。外部サーバーへ送信されることはなく、ご主人様のブラウザ内（ローカル）にのみ保存されますので安全です。
