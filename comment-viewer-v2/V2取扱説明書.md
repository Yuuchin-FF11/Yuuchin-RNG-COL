# 配信コントロールセンター V2 取扱説明書

APIキー不要で無制限にYouTubeライブチャットを自動取得・翻訳し、高精度な音声合成（ななみちゃん）で読み上げる配信支援ツールの最新版（V2）です。

---

## 1. このツールを導入することで、具体的にどのような作業が楽になるのか（導入メリット）

・【YouTube APIキーの取得とクォータ管理からの完全解放】
  従来の配信翻訳ツールでは、Google CloudでAPIキーを発行し、毎日10,000ユニットのクォータ上限を気にしながら配信する必要がありました。本ツールはコメビュ方式を採用しているため、APIキーの発行・登録が一切不要です。10時間を超える長時間のゲーム配信でも枠切れ（クォータ制限）を気にせず、完全に無料で使い続けられます。

・【配信中のコメント読み落とし・マルチタスク負担のゼロ化】
  ゲームに熱中している最中やボス戦の真っ只中でも、届いたコメントをななみちゃんが自然な日本語音声で読み上げてくれます。画面から目を離してコメント欄を確認する頻度が劇的に減り、ゲームプレイとトークに100%集中できます。

・【海外リスナーとの言葉の壁を自動で解消】
  英語や韓国語など海外から届いたコメントをリアルタイムに日本語訳して読み上げます。さらに、配信者の日本語マイク音声を自動でリアルタイム英訳して画面におしゃれな字幕カードとしてポップアップ表示するため、英語が話せなくても海外リスナーと自然な双方向コミュニケーションが成立します。

---

## 2. このツールを使うと、具体的にどのようなことができるのか（機能の直感的な要約）

・【YouTubeライブチャットの自動取得と画面オーバーレイ表示】
  YouTubeの配信URLまたは動画IDを入力して接続するだけで、届いたチャットをOBS画面上に美しくアニメーション表示します。文字サイズ、表示秒数、最大同時表示数などを自由にカスタマイズ可能です。

・【ななみちゃん（オンライン音声合成）による滑らかな自動読み上げ】
  Microsoft Edgeの自然なオンライン音声（ななみちゃん）を用いて、届いたチャットを高品質に読み上げます。「日本語訳のみ」「原文ネイティブ発音＋日本語訳」「原文のみ」の3パターンから配信スタイルに合わせて選択できます。

・【配信者マイク音声のリアルタイム英訳字幕】
  配信者がマイクで喋った日本語をブラウザが認識し、即座に英訳してOBS画面に字幕カードとして表示します。手動入力欄も備えており、マイクが使えない環境でも手入力したメッセージを英訳して画面に出すことができます。

・【スパチャ・メンバーシップの自動検知と効果音通知】
  スーパーチャットや新規メンバーシップが届いた瞬間に、専用の効果音を自動再生してリスナーへの感謝のタイミングを逃しません。

・【お上品フィルター（NGワード伏字・スキップ機能）】
  荒らしや不適切な単語を自動で検知し、画面上では伏字（●●）に変換し、音声読み上げではスキップして配信の安全を守ります。独自の追加NGワードも自由に登録可能です。

・【読み上げ辞書・音声認識誤字修正テーブル】
  ゲーム内の固有名詞やネットスラングなど、AIが読み間違えやすい単語を「変換前」「読ませる言葉」のペアで登録し、正しく発音させることができます。

## 3. 他の生成AIツール等と連携して活用する方法（AIシナジー）

・【ChatGPTやClaudeによる配信ダイジェスト・切り抜き要約の自動生成】
  管理画面の「配信中のチャット履歴（自動翻訳ログ）」エリアには、配信中に届いたすべてのコメントと翻訳文が時系列で蓄積されます。このチャットログをコピーしてChatGPTやClaudeに渡すことで、「リスナーが一番盛り上がったシーンのタイムスタンプ抽出」や「配信のダイジェストブログ記事・SNS告知文の自動生成」が一瞬で行えます。

・【AIキャラクター（VOICEVOX / ローカルLLM）との対話配信への拡張】
  本ツールのローカルサーバー（http://localhost:8080/api/chat）は、受信したチャットデータをJSON形式で配信しています。Pythonスクリプト等からこのAPIをポーリングすることで、ローカルで動くLLM（大規模言語モデル）にコメントを読ませて自動で相槌を打たせたり、VOICEVOXのキャラクターと掛け合い配信を行うなど、最先端のAI配信システムへと発展させることが可能です。

## 4. V2における主な改善点（前バージョンからの進化）

1. 【ポート自動追従の安全起動】
   ポート8080を使用している既存の他プロセスを強制終了する危険な処理を撤廃しました。8080〜8090の中から安全に空きポートを自動検出し、ブラウザがそのポートへ自動追従して起動します。

2. 【ななみちゃんの読み上げレスポンス向上】
   発話ごとに毎回実行されていたウォームアップ処理（微小音量発話）を廃止し、定期バックグラウンド・キープアライブ方式に切り替えました。これにより、コメント受信から声が出るまでの待ち時間（レイテンシ）が大幅に短縮されました。

3. 【音声認識の自律復旧とマイク競合防止（ロングセッション対応）】
   長時間のゲーム配信における無言タイム（カットシーンや集中時など）での誤爆切断を防ぐため、正常稼働中の定期リビルドを撤廃し、無音応答（no-speech）の正常検知と10分間のゾンビ保護ロジックに最適化しました。また、インスタンス再構築時に800ミリ秒のデバイス解放インターバルを設けることで、長時間の連続配信でもマイクが勝手に停止しない超安定設計へと進化しました。

4. 【ファイル構成の一本化とコードクリーンアップ】
   混乱の原因となっていたadmin.htmlと管理画面.htmlの乖離を解消し、最新仕様で一本化しました。また、プロジェクト規約に従い、コード・UI・ログから禁止絵文字を完全に一掃しました。

---

## 5. ご使用手順

1. フォルダ内の「起動_コメビュV2.bat」をダブルクリックして起動します。
2. YouTube Studioで配信枠（またはテスト配信）を作成し、その配信URLをコピーします。
3. 管理画面の「配信URL」欄に貼り付け、「接続」ボタンをクリックします。
4. 生成された「OBS連携用URL」をコピーし、OBSの「ブラウザソース」のURL欄に貼り付けます。
5. OBS側で「現在のページのキャッシュをクリア」を押して画面を更新すれば連携完了です。
6. 配信を終了する際は、「停止_コメビュV2.bat」を実行するか、起動時の黒いコマンドプロンプト画面を閉じてください。
