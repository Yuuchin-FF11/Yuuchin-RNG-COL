# Smart Document & Data Generator Skill

## Description
このスキルは、プロジェクトの文脈を読み取り、高品質なプレゼンテーション資料（Markdown形式）やデータ集計表（CSV/HTML Table形式）を自動生成します。

## Instructions
1. **スライド構成の自動化**: `Marp` や `Reveal.js` 形式のMarkdownを使用して、即座にプレゼン可能なスライドを生成します。
2. **データ分析と可視化**: テキストベースのデータを構造化し、HTMLのテーブルやグラフ（Chart.js等）で表示可能な形式に変換します。
3. **要約とレポート**: 長大なコードや議論を、エグゼクティブサマリーとして簡潔にまとめます。

## Usage
- "このプロジェクトの進行状況をスライド形式でまとめて"
- "現在の装備一覧を比較表（テーブル）にして"
