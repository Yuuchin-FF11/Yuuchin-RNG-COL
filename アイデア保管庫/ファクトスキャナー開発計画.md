# 【アイデア企画書】ファクト・スキャナー（Fact Scanner）開発計画

コードの修正やバグ調査の前に、アセット（画像やデータ）の物理的な「実態（ファクト）」を自動検証し、開発者やAIアシスタントの「憶測・思い込み」によるバグを未然に防ぐためのリソーススキャンシステム。

---

## 1. 背景と動機
ソフトウェア開発やUI調整において、以下のような「憶測」に起因するバグが頻発します。
- コード上の描画領域サイズ（例: 572x512）を、画像ファイルの実際の解像度だと思い込んで座標計算（切り抜き等）を行い、完全に範囲外を指定してしまう（AIや人間の勘違い）。
- 読み込むべき画像やデータのパスがコード上で間違っていることに気づかず、エラーの原因究止に何時間も費やす。

### 解決策
コードを変更する「前」に、そのコードが依存している物理ファイル（画像など）の実態を強制的に調査させ、実際のサイズや仕様を突きつける仕組み（ファクト・スキャナー）を構築します。

---

## 2. システムのコア仕様
スキャン対象のソースコード（HTML, JavaScript, CSS等）を解析し、以下の検証を自動で行います。

・**アセットパスの自動抽出**: コード内の引用符から `*.png`, `*.jpg`, `*.gif`, `*.json` などのパスを検出。
・**物理存在チェック**: 該当するファイルが指定フォルダやプロジェクト内に実在するかを判定。
・**仕様（解像度・容量）の取得**: 
  - 画像の場合: 実際のピクセル幅・高さを解析して取得。
  - データの場合: JSONのキー構造やサイズを取得。
・**乖離の警告（Web版）**: コード内で指定されている数値（例: `drawImage` の幅）と、実際の画像の幅に乖離がある場合にビジュアルで警告を出す。

---

## 3. アプリケーションの展開アプローチ

### フェーズ 1: コマンドライン・ローカル版（実装済）
- **概要**: `fact_scanner.ps1` (PowerShell) / `fact_scanner.py` (Python)。
- **用途**: 開発者がローカル環境で直接実行し、Markdown形式の「事実検証レポート（fact_report.md）」を出力して確認する。
- **特徴**: Windows標準の.NETアセンブリ（System.Drawing）を使用することで、追加の環境構築やライブラリインストールなしで100%動作する。

### フェーズ 2: Webアプリケーション・プロトタイプ版（今回作成）
- **概要**: `fact_scanner_app.html`。HTML + CSS + JS の1ファイルで構成されるブラウザツール。
- **特徴**: 
  - サーバー代や維持費が完全無料（ユーザーのブラウザ内で全ての処理が完結）。
  - ドラッグ＆ドロップによる直感的なインターフェース。
  - 美しいダークモードとネオンカラーを基調とした、プレミアムでインタラクティブなUIデザイン。
- **ターゲット層**: 趣味のWeb開発者、プログラミング初心者、AIエージェントと共同開発を行うユーザー。

---

## 4. 将来的な展望と拡張機能
- 【AIエージェントの検証前チェック機構としての統合】:
  AIがソースコードを変更しようとする際、システムが自動でこのスキャナーを実行し、結果をAIのプロンプト（コンテキスト）に自動で差し込むことで、AIのハルシネーション（思い込み）によるバグの発生確率をほぼゼロにする。
- 【VS Code拡張機能（プラグイン）化】:
  エディタ内でコードを保存した瞬間に、裏で自動スキャンが走り、解像度が一致しない箇所に黄色の波線で警告を出す。

## 5. マネタイズと模倣への防衛策（セキュリティ設計）
このシステムを一般公開・製品化するにあたり、競合他社による模倣（ソースコードのコピー）を防ぎ、ビジネスの優位性を確保するための防衛策。

・【コアロジックのブラックボックス化（サーバーサイド処理）】
  ファイルの解析処理や解像度比較の主要ロジックを、フロントエンド（HTML/JS）ではなく、サーバーサイド（Python等）に実装する。ユーザーには解析結果のデータのみを送信し、内部のソースコードや解析アルゴリズムを外部から完全に隠蔽する。
・【フリーミアムモデルによる先発優位の獲得】
  1ファイルのスキャンなどの基本機能を「無料版（お試し）」として公開し、知名度とユーザーコミュニティを急速に獲得して「本家」としてのブランドを確立する。
  一方で、複数ファイルの一括スキャン、AI自動修正コード提案、PDFレポート出力などの高度な機能を有料プラン（サブスクリプション）として制限し、マネタイズを行う。
