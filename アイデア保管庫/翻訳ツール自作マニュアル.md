# APIキー完全不要！OBS用リアルタイム翻訳コメビュ自作マニュアル

このマニュアルは、自分の配信画面にリアルタイムで「喋った声の翻訳字幕」を表示させ、さらに「翻訳後の声を自動で読み上げ」させるツールを自作するためのガイドです。

難しいプログラミングサーバーの設定はもちろん、Google Cloudなどの「APIキーの取得・設定」も一切不要。HTMLとJavaScriptという基本的なホームページの技術だけで、同じPC上のブラウザ同士が通信（ローカルストレージ連携）する仕組みを採用しています。

ファイルをダブルクリックで開くだけで、誰でもすぐに完全無料で翻訳字幕＆音声読み上げシステムを動かすことができます。

---

## 1. 作成するツールの全体イメージと仕組み
作成するツールは、以下の２つの画面で構成されます。

- 【コントロールパネル（admin.html）】
  - 配信者のマイク音声をブラウザが認識し、自動で文字起こしします。
  - 文字起こしされた日本語を、無料のGoogle翻訳APIを使って一瞬で英語に自動翻訳します。
  - 【追加機能】翻訳された英語を、ブラウザ標準の音声合成機能を使ってネイティブな発音で自動読み上げします（ON/OFF切り替え可能）。
  - 翻訳されたデータを、PC内の共通メモリ（ローカルストレージ）へ書き込みます。
- 【配信表示用オーバーレイ（overlay.html）】
  - 共通メモリへの書き込みをリアルタイムに検知し、画面上に美しいアニメーション付きで翻訳字幕を表示します。
  - この画面をOBS Studioのブラウザソースとして読み込ませます。

## 3. ファイルの作成手順

作業用のフォルダ（例：「翻訳ツール」）をデスクトップなどに新規作成し、その中に以下の２つのファイルをエディタで作って保存します。

### ファイル①：コントロールパネル「admin.html」
以下のコードをすべてコピーして、ファイル名「admin.html」として保存してください。
※音声読み上げ機能（SpeechSynthesis）と、そのON/OFF切り替えスイッチを搭載しています。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <title>翻訳コントロールパネル</title>
    <style>
        body {
            font-family: 'Helvetica Neue', Arial, sans-serif;
            background: #0f172a;
            color: #f8fafc;
            padding: 20px;
            max-width: 600px;
            margin: 0 auto;
        }
        h1 {
            color: #38bdf8;

        }

            font-size: 16px;

        }
        button:hover { background: #0369a1; }

        }
        .log-box {

            overflow-y: auto;
            background: #0f172a;

            border-radius: 5px;
            font-size: 14px;
            border: 1px solid #1e293b;
        }
        .checkbox-container {
            display: flex;
            align-items: center;
            margin-top: 10px;

</head>
<body>
    <h1>翻訳コントロールパネル</h1>
    
    <div class="box">
        <button id="start-btn">音声認識を開始する</button>
        <div id="status" class="status">停止中（マイクの許可が必要です）</div>
        
        <!-- 音声読み上げのON/OFF切り替え -->
        <label class="checkbox-container">
            <input type="checkbox" id="tts-enable" checked>
            翻訳された英語を自動で読み上げる（音声合成）
        </label>
    </div>

    <div class="box">
        <h3>認識した音声 (日本語)</h3>
        <div id="original-text" style="color: #38bdf8; font-weight: bold; min-height: 24px;"></div>
    </div>

    <div class="box">
        <h3>翻訳結果の履歴</h3>
        <div id="log" class="log-box"></div>
    </div>

    <script>
        const startBtn = document.getElementById('start-btn');
        const statusDiv = document.getElementById('status');
        const originalTextDiv = document.getElementById('original-text');
        const logDiv = document.getElementById('log');
        const ttsEnable = document.getElementById('tts-enable');

        let recognition;
        let isRecognizing = false;

        // --- 音声認識（文字起こし）の処理 ---
        if ('webkitSpeechRecognition' in window || 'SpeechRecognition' in window) {
            const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
            recognition = new SpeechRecognition();
            recognition.lang = 'ja-JP';
            recognition.continuous = true; // 喋り終わっても自動停止しない設定
            recognition.interimResults = true; // 喋っている途中の文字を表示する

            recognition.onstart = () => {
                statusDiv.innerText = 'マイク入力音声の認識中...（お喋りしてください）';
                statusDiv.style.color = '#4ade80';
                startBtn.innerText = '音声認識を停止する';
                startBtn.style.background = '#dc2626';
            };

            recognition.onend = () => {
                statusDiv.innerText = '停止中';
                statusDiv.style.color = '#94a3b8';
                startBtn.innerText = '音声認識を開始する';
                startBtn.style.background = '#0284c7';
                isRecognizing = false;
            };

            recognition.onresult = async (event) => {
                let interimTranscript = '';
                let finalTranscript = '';

                for (let i = event.resultIndex; i < event.results.length; ++i) {
                    if (event.results[i].isFinal) {
                        finalTranscript += event.results[i][0].transcript;
                    } else {
                        interimTranscript += event.results[i][0].transcript;
                    }
                }

                if (interimTranscript) {
                    originalTextDiv.innerText = interimTranscript;
                }

                if (finalTranscript) {
                    originalTextDiv.innerText = finalTranscript;
                    addLog(`音声確認: ${finalTranscript}`);
                    translateAndSend(finalTranscript);
                }
            };
        } else {
            statusDiv.innerText = 'お使いのブラウザは音声認識非対応です（Google Chrome推奨）';
            startBtn.disabled = true;
        }

        startBtn.onclick = () => {
            if (isRecognizing) {
                recognition.stop();
            } else {
                recognition.start();
                isRecognizing = true;
            }
        };

        // --- APIキー不要のGoogle翻訳 ＆ データ送信処理 ---
        async function translateAndSend(text) {
            if (!text) return;
            try {
                const url = `https://translate.googleapis.com/translate_a/single?client=gtx&sl=ja&tl=en&dt=t&q=${encodeURIComponent(text)}`;
                
                const response = await fetch(url);
                if (!response.ok) throw new Error('翻訳に失敗しました');

                const data = await response.json();
                
                if (data && data[0] && data[0][0] && data[0][0][0]) {
                    const englishText = data[0][0][0].trim();
                    addLog(`翻訳後: ${englishText}`);

                    // 読み上げ設定がONの場合、英語音声で読み上げを実行
                    if (ttsEnable.checked) {
                        speakEn(englishText);
                    }

                    // ローカルストレージに書き込み（OBSへのデータ同期）
                    const messageData = {
                        id: Date.now(),
                        ja: text,
                        en: englishText
                    };
                    localStorage.setItem('translation_message', JSON.stringify(messageData));
                }
            } catch (error) {
                console.error(error);
                addLog('エラー：翻訳の通信に失敗しました。');
            }
        }

        // --- 英語の音声合成（読み上げ）処理 ---
        function speakEn(text) {
            if ('speechSynthesis' in window) {
                // 前の発声の残りをキャンセルして二重読み上げを防ぐ
                window.speechSynthesis.cancel();

                const utterance = new SpeechSynthesisUtterance(text);
                utterance.lang = 'en-US'; // 英語（米国）の発音を指定

                // ブラウザに搭載されている英語の声を選択（優先適用）
                const voices = window.speechSynthesis.getVoices();
                const englishVoice = voices.find(voice => voice.lang.startsWith('en'));
                if (englishVoice) {
                    utterance.voice = englishVoice;
                }

                window.speechSynthesis.speak(utterance);
            }
        }

        // ページ読み込み時に音声リストを初期化（ブラウザ対策）
        if ('speechSynthesis' in window) {
            window.speechSynthesis.getVoices();
        }

        function addLog(msg) {
            const p = document.createElement('p');
            p.style.margin = '2px 0';
            p.innerText = msg;
            logDiv.appendChild(p);
            logDiv.scrollTop = logDiv.scrollHeight;
        }
    </script>
</body>
</html>
```

### ファイル②：表示用画面「overlay.html」
以下のコードをすべてコピーして、ファイル名「overlay.html」として保存してください。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <title>OBS用翻訳字幕オーバーレイ</title>
    <!-- 
        OBS用翻訳字幕オーバーレイのスタイル設定
        - bodyのbackgroundはOBSで背景透過させるためにtransparent（透明）に設定しています
        - subtitle-boxのbackgroundは半透明のディープネイビー背景です
        - borderは上品な半透明ゴールドの枠線、box-shadowはほのかな光彩です
        - backdrop-filterはガラスのような磨りガラス効果を適用します
        - animationはフェードイン・スライドアップのアニメーションです
        - fade-outクラスはゆっくり消える際のアニメーションを適用します
    -->
    <style>
        body {
            margin: 0;
            padding: 0;
            background: transparent;
            overflow: hidden;
            font-family: 'Impact', 'Arial Black', sans-serif;
        }
        #subtitle-container {
            position: absolute;
            bottom: 30px;
            left: 50%;
            transform: translateX(-50%);
            width: 90%;
            text-align: center;
        }
        .subtitle-box {
            display: inline-block;
            background: rgba(15, 23, 42, 0.75);
            color: #ffffff;
            font-size: 28px;
            padding: 10px 25px;
            border-radius: 12px;
            border: 2px solid rgba(234, 179, 8, 0.4);
            box-shadow: 0 0 15px rgba(234, 179, 8, 0.2);
            backdrop-filter: blur(8px);
            text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.8);
            
            animation: slideUp 0.4s ease-out forwards;
            opacity: 0;
        }
        @keyframes slideUp {
            from {
                transform: translateY(20px);
                opacity: 0;
            }
            to {
                transform: translateY(0);
                opacity: 1;
            }
        }
        .fade-out {
            transition: opacity 0.8s ease-out;
            opacity: 0;
        }
    </style>
</head>
<body>
    <div id="subtitle-container">
        <!-- ここに字幕が動的に入ります -->
    </div>

    <script>
        const container = document.getElementById('subtitle-container');
        let activeTimeout;

        // ローカルストレージ（共通メモリ）の変更イベントを監視
        window.addEventListener('storage', (event) => {
            if (event.key === 'translation_message' && event.newValue) {
                const data = JSON.parse(event.newValue);
                showSubtitle(data.en); // 英語の翻訳結果を表示
            }
        });

        function showSubtitle(text) {
            clearTimeout(activeTimeout);
            container.innerHTML = '';

            const div = document.createElement('div');
            div.className = 'subtitle-box';
            div.innerText = text;
            container.appendChild(div);

            activeTimeout = setTimeout(() => {
                div.classList.add('fade-out');
                activeTimeout = setTimeout(() => {
                    container.innerHTML = '';
                }, 800);
            }, 5000);
        }
    </script>
</body>
</html>
```

## 4. 使い方（動かし方）
ファイルを保存したら、以下の手順ですぐに使い始めることができます。

1. <b>コントロールパネルの起動</b>
   - 作成した「admin.html」を、Google Chrome等のブラウザでダブルクリックして開きます。
2. <b>マイクの使用許可</b>
   - 「音声認識を開始する」ボタンをクリックします。ブラウザの上部に「マイクの使用許可」を求めるポップアップが出るので、「許可」を選択します。
3. <b>読み上げのテスト</b>
   - コントロールパネルの「翻訳された英語を自動で読み上げる」にチェックが入っていることを確認します。
   - マイクに向かって日本語で喋ると、翻訳された英語テキストがスピーカーから合成音声で自動発声されます。
4. <b>OBSへの字幕画面の取り込み</b>
   - OBS Studioを起動します。
   - ソースパネルの「＋」ボタンをクリックし、「ブラウザ」を追加します。
   - プロパティ設定で「ローカルファイル」にチェックを入れ、「参照」ボタンから作成した「overlay.html」を選択して読み込みます。
   - OBS のブラウザソースのサイズは、横「1280」、縦「720」に設定すると、画面下部の中央に綺麗に字幕が収まります。

## 5. 購入者を引きつけるカスタマイズのヒント
マニュアルの購入者へ「自分好みにアレンジする方法」として、以下のカスタマイズのヒントを紹介しています。

- 【字幕のフォントや色の変更】: `overlay.html` の `style` 内にある `color` や `font-family` を書き換えることで、自分の配信のゲームジャンル（ドット絵風、ファンタジー風など）に完璧に合わせることができます。
- 【翻訳言語と読み上げ言語の変更】: 
  - `admin.html` 内の翻訳URLにある `tl=en`（英語）の部分を、`tl=ko`（韓国語）に書き換えることで、韓国語への翻訳に変更できます。
  - その際、読み上げ処理（`speakEn` 関数内）の `utterance.lang = 'en-US';` を `utterance.lang = 'ko-KR';` に書き換えることで、読み上げる音声も韓国語の正しい発音に自動追従させることができます。
