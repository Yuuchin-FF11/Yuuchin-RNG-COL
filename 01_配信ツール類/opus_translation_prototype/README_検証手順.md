# ローカルAI翻訳（Helsinki-NLP / OPUS-MT）プロトタイプ検証ガイド

本フォルダは、販売用アプリ（配信コントロールセンター）に影響を与えずに、完全ローカル＆APIキー不要の商用AI翻訳モデル（Helsinki-NLP）を単体でテスト・評価するための独立したプロトタイプ環境です。

---

## 1. 検証の目的
- **商用ライセンス（Apache-2.0）モデルの実用性確認**
  - 日本語 → 英語：`Helsinki-NLP/opus-mt-ja-en`
  - 英語 → 日本語：`Helsinki-NLP/opus-mt-en-jap`
- **初回ダウンロード容量とキャッシュ動作の確認**
  - ブラウザの Cache Storage（IndexedDB）に一度保存されれば、次回以降はオフラインで即起動するか。
- **推論速度（ミリ秒）と翻訳精度の実測**
  - 配信者のマイク発言やリスナーのコメントの速度に耐えうるか。

---

## 2. 起動と検証手順
1. 本フォルダ内の `起動.bat` をダブルクリックします。
2. ポート8090で軽量ローカルサーバーが立ち上がり、専用の検証ウィンドウ（Edge）が開きます。
3. 「両モデルを事前ダウンロード・初期化」をクリックして、ダウンロード速度とキャッシュ保存の挙動を確認します。
4. テスト用例文（または自由な入力）で「翻訳を実行する」をクリックし、所要時間（ms）と翻訳結果の自然さを確認します。

---
