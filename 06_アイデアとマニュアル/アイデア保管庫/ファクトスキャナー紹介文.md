# ファクトスキャナー 販売紹介文

【キャッチコピー】
コード変更「前」に物理アセットを自動検証！開発者とAIエージェントの思い込みバグを根絶する「ファクトスキャナー」
コード内の画像パスの実在チェックから、実際のピクセル解像度とコード指定値のズレまでを自動スキャンし、不一致をビジュアル警告します。

【Web開発者やAI共同開発を行っている皆さん、こんなトラブルはありませんか？】
- 画像を表示・切り抜くコードを書いたが、画像の物理的な縦横サイズを勘違いしていて画面表示が崩れた
- 参照している画像のファイル名やパス（フォルダ位置）が間違っていることに気づかず、原因究明に何時間も費やした
- AIアシスタントに画像の座標計算を依頼したら、AIが適当なサイズを脳内補完して全くずれた数値を指定してきた

そのトラブル、この「ファクトスキャナー」がすべて解決します。

【このツールが選ばれる３つの理由】

１. アセットの実在とパスの自動チェック
ソースコード（HTML, CSS, JS等）を解析し、プログラムの中で引用されている画像（PNG, JPG等）やデータ（JSON等）が、プロジェクト内に物理的に存在しているかを瞬時に判定します。

２. コード上の数値と「物理ファイルの実際の解像度」の乖離をスキャン
「コードが指定している描画幅」と「画像ファイル本来のピクセルサイズ」を突き合わせ、ズレや範囲外の指定（切り抜き時のサイズオーバーなど）がある場合に赤枠で警告を出します。AIの思い込みによる座標指定バグを水際で防ぐことができます。

３. 開発環境の構築不要ですぐに動く軽量ポータブル仕様
外部の重いライブラリや有料サービスに依存しないため、ダウンロードしてブラウザで開くだけで動作します。余計な維持費やサーバー代は一生ゼロです。

【商品内容】
- ファクトスキャナー アプリ本体（HTML ＋ CSS ＋ JS）
- 監視サーバープログラム（Python版 ＆ PowerShell版）
- テスト用ダミー画像およびサンプルコード
- 取扱説明書マニュアル

AIエージェントにコードを書き換えさせる「直前」にこの検証を挟むことで、勘違いによるバグの発生確率をほぼゼロにできます。
開発の手戻りを防ぎ、作業効率を劇的に引き上げる開発の必須パートナーです。
