## 1. 狩人・コルセア主要武器（RMEAP＋Su5武器）

### 狩人専用・主要武器

* 【与一の弓】（Yoichinoyumi）

* 【アナイアレイター】（Annihilator）
  * 分類：レリックウェポン（射撃）
  * 用語辞典URL：https://wiki.ffo.jp/html/3080.html （記事ID: 3080）
  * 性能特徴：固有WS「カラナック」が使用可能。敵対心マイナスおよび強力な飛命・飛攻ブースト。

* 【ガーンデーヴァ】（Gandiva）
  * 分类：エンピリアンウェポン（弓術）
  * 用語辞典URL：https://wiki.ffo.jp/html/20383.html （記事ID: 20383）
  * 性能特徴：エンピリアンWS「ジシュヌの光輝」が使用可能。

* 【シャランガ】（Sharanga）
  * 分類：ジョブマスター専用武器（スペリア5 / Su5）（クロスボウ）
  * 用語辞典URL：https://wiki.ffo.jp/html/37295.html （記事ID: 37295）
  * 性能特徴：高い飛命、魔法ダメージ、スナップショットを持つ高性能クロスボウ。

* 【ピナカ】（Pinaka）
  * 分類：プライムウェポン（弓術）

  * 性能特徴：ソーティ（シャルヴ）やガリモーフリーを用いて強化するプライムウェポン。専用のプライムWSが使用可能。

### コルセア専用・主要武器

* 【デスペナルティ】（Death Penalty）
  * 分類：ミシックウェポン（射撃）
  * 用語辞典URL：https://wiki.ffo.jp/html/483.html （記事ID: 483）
  * 性能特徴：固有WS「レデンサリュート」のダメージを極限まで高める銃。クイックドロー性能アップを所持。

* 【ラヌンナイフ】（Lanun Knife）
  * 分類：ジョブ専用武器（スペリア4 / Su4）（短剣）

* 【ロスタム】（Rostam）
  * 分類：ジョブマスター専用武器（スペリア5 / Su5）（片手剣）
  * 用語辞典URL：https://wiki.ffo.jp/html/37261.html （記事ID: 37261）
  * 性能特徴：Type:A（射撃）、Type:B（殴り）、Type:C（ロール支援）の3つの強化パスを持ち、特にType:Cは「ロール効果時間延長」「ロール性能強化」を併せ持つ必須装備。

## 2. アブゾ系魔法（アブゾタックなど）のシステム仕様

* 【レジストの概念がない】
  * アブゾ系（吸魔）暗黒魔法（アブゾタック、アブゾイン、アブゾデック等）には、効果が半分やクォーターに減衰する「レジスト」の概念は存在しません。
  * 効果は「フルヒット（100%入る）」か「完全ミス（NO EFFECT / 効果なし）」のいずれか二者択一です。
* 【魔法命中上限95%キャップ】
  * FF11のシステム仕様上、プレイヤーの魔法命中率がどれだけ敵の魔法回避率を上回ってブーストされていても、魔法命中率の上限は「95%」でキャップされます。
  * そのため、最高峰 of 魔命装備を揃えていても、5%の確率で必ずミス（NO EFFECT）する「運ゲー」が必ず存在します。「100%必中」と記述することはゲームシステム上、誤りです。
* 【翻訳・表記ルール】
  * 日本語の記事や装備解説において、無用な英語直訳（例：ノーエフェクト）は避け、日本語として読みやすいように「完全ミス」や「効果なし」とスッキリ表現します。

## 3. コルセア専用ジョブ仕様

### ファントムロール（Phantom Roll）
* 用語辞典URL：https://wiki.ffo.jp/html/3347.html （記事ID: 3347）
* 基本リキャスト：60秒（1分）
* 効果時間：通常300秒（5分）
* 出目「XI（11）」の特殊効果：
  * ロールの再使用時間（リキャスト）を即座にリセット。
  * XIの効果を得ている間、ロールのリキャストが30秒に短縮。
  * XIの効果を得ている間、他のロールがバスト（合計12以上）しても、効果が切れるだけでバストペナルティ（ステータスマイナス効果およびロール枠占有）を受けない。

### クイックドロー（Quick Draw）とエンピ足
* デスペナルティのクイックドロー性能アップ：
  * クイックドローのダメージ+20%、魔法命中率+20（強化ランクに応じてさらに各+10ずつアップ）。
* エンピリアン足装備【シャスーブーツ / ＣＳブーツ】
  * 用語辞典URL：https://wiki.ffo.jp/html/33253.html （記事ID: 33253）
  * プロパティ名：「クイックドロー能力+」
  * 効果：クイックドローを命中させた敵に対して、次に着弾する同属性魔法のダメージを上昇させる。
  * 強化段階毎のダメージ上昇効果量：
    * ＣＳブーツ+1：魔法ダメージ+20%
    * ＣＳブーツ+2：魔法ダメージ+25%
    * ＣＳブーツ+3：魔法ダメージ+31%

## 4. 攻略情報の参照・検索鉄則（AI再発防止ルール）

* 【泥臭い一次ソース裏取り】
  * 用語辞典等の静的URLを参照・追加する際は、Google検索の簡易プレビューやAIの脳内自動補完を絶対に過信しない。
  * 必ず「PowerShell検索スクリプト（scratch/search.ps1）」を実行して、用語辞典のCGIから直接本物の記事データを取得し、記事IDおよびタイトルタグ（titleタグ）がターゲットのアイテム名そのものであることを100%直接目視確認してから反映する。
* 【でっち上げの完全禁止】
  * 存在しない装備名（例：ニャメフランシズ、ニャメフランケ、シャシュニャール等）や、ジョブが装備できない武器種、間違った数値データを予測で書くことは絶対に、永久に禁止。
  * 攻略記事の中身（文章や装備セットの組み合わせ自体）は、100%完全にご主人様が執筆される一次ソースをベースとし、AIは誤字脱字の修正、Markdown/HTMLテーブル適用などの美的整形・推敲に徹底して専念する。
