# 資料生成ワークフロー (Smart Doc Generator)

このワークフローは、導入済みの `smart_doc_generator` スキルを使用して、高品質な資料を自動生成します。

## 手順

1. **コンテキストの収集**:
   - 現在のコード、コミット履歴、およびプロジェクトルールをスキャンして情報を集めます。
2. **構成案の作成**:
   - 目的（進捗報告、装備比較など）に合わせて、スライドの構成案を提案します。
3. **成果物の生成**:
   - `Marp` (Markdown Presentation) 形式のスライド、または HTML/CSV 形式の比較表を出力します。
4. **プレビュー**:
   - 生成されたファイルをブラウザで開き、内容を確認します。

## 使用例
- `/generate-docs スライド形式でプロジェクトの概要をまとめて`
- `/generate-docs 現在の全装備の性能比較表を作成して`
