# 翻訳アプリのデスクトップアプリ（コメビュ方式）化 実装計画書

このドキュメントは、現在のブラウザソース版（YouTube APIキー必須）から、APIキー不要で無限に動作する「デスクトップアプリケーション（マルチコメントビュアー形式）」への将来的な移行に向けた準備・設計メモです🐾

---

## 1. 目的とメリット
* **APIキーの完全撤廃**：Google Cloudのクォータ上限（1日10,000制限）を気にせず、8時間以上のゲーム配信でも完全無料で無限に動作するようにします。
* **初期設定の簡略化**：配信URLを入力するだけで動作し、ご主人様（配信者）がAPIキーを作成・管理する手間をなくします。

---

## 2. 技術選定（フレームワーク比較）

デスクトップアプリ化（Windows用の `.exe` アプリ化）にあたり、以下の2つのフレームワークが最有力候補です。

### 候補①：Tauri（タウリ） ★最も推奨🐾
* **概要**：画面はHTML/CSS/JSで描き、裏側の処理（OS制御やファイル操作）をRustで行う最新の軽量フレームワーク。
* **メリット**：
  * アプリのファイルサイズが非常に小さい（約3MB〜5MB程度）。
  * 動作が極めて軽量で、ゲーム配信中のPCのCPU・メモリ負荷を最小限に抑えられます🐾
  * セキュリティが非常に堅牢。
* **デメリット**：裏側（ファイル保存など）の処理を書く際にRustの知識が必要（AIがサポートするためご主人様は心配不要です）。

### 候補②：Electron（エレクトロン）
* **概要**：VS CodeやDiscordなどでも使われている、Web技術だけでデスクトップアプリを作る老舗フレームワーク。
* **メリット**：
  * すべてJavaScript/Node.jsだけで完結するため、現在のコード（`admin.js`）をほぼそのまま流用可能。
* **デメリット**：
  * アプリのサイズが非常に肥大化しやすい（最小でも80MB以上）。
  * メモリやCPUの消費が大きく、長時間のゲーム配信時にPCの動作に影響を与えるリスクがあります。

**🐾 結論**: ゲーム配信の快適さを最優先するため、PCへの負荷が最も低い **「Tauri」** を採用する方向で準備を進めます。

---

## 3. アプリケーション設計とOBS表示 of 仕組み

デスクトップアプリになっても、最終的にOBSの画面に吹き出し（字幕）を表示させるための仕組みは、以下のように設計します。

```mermaid
graph TD
    subgraph パソコン内 (Local PC)
        App[デスクトップアプリ: Tauri] -->|YouTubeの裏画面をロード| YT[YouTubeチャット欄]
        YT -->|HTMLスクレイピングでコメント取得| App
        App -->|APIキー不要でリアルタイム翻訳| App
        App -->|ローカルHTMLファイルを更新| OutputHtml[overlay.html]
    end
    subgraph 配信ソフト (OBS)
        OBS[OBS Studio: ブラウザソース] -->|ローカルファイル読み込み| OutputHtml
    end
```

### 🐾 コメントの取得方法（CORS制限の突破）
* アプリの内部で、通常のブラウザがYouTubeのチャット画面（HTML）を開く通信を模倣し、そこからHTMLデータを読み取ってチャットを抽出（スクレイピング）します。
* これにより、セキュリティ制限（CORS）を受けずに、APIキー不要で安全にコメントを取得できます。

### 🐾 OBSとの連携
* アプリが自動的にローカルフォルダ内の `overlay.html` に字幕データを書き出し、OBS側はそれを「ローカルファイルのブラウザソース」として取り込むだけで、これまでと全く同じ美しい吹き出しアニメーションが画面に表示されます🐾

## 4. 今後の開発ロードマップ（計画）

1. **ステップ1：プロトタイプの作成（APIキー不要のチャット取得テスト）**
   * バックグラウンド処理にて、YouTubeの限定公開・公開配信からAPIキーなしでチャットデータを安定して抽出できるJavaScript/Rustコードのプロトタイプを検証します。
2. **ステップ2：Tauri環境の構築と移植**
   * 現在の `index.html`（管理画面）と `overlay.html` を Tauri のUIとして組み込み、デスクトップアプリとしてビルドできる環境を整えます。
3. **ステップ3：ご主人様によるテストとデプロイ**
   * Windows用の起動ファイル（`.exe`）を作成し、ご主人様のPCで動作確認を行っていただきます🐾

## 5. アプリの販売・コスト管理プラン（ご主人様ご検討用）🐾

ご主人様に追加の費用負担や赤字リスク（逆ザヤ）が一切発生しない安全な運用プランの設計です。

### 🐾 提供形態と価格目安
* **提供方式**：月額サブスクリプション方式（APIキー不要のプロ仕様として提供）
* **月額料金目安**：1,200円〜1,500円
* **翻訳制限枠**：ユーザー1人あたり月間40万文字まで（一般的な配信者であれば十分足りる量です）

### 🐾 月間制限（40万文字）超過時のハイブリッド挙動
制限に達した際は翻訳機能を一時停止し、以下のいずれかの方法で再開・継続できるように制御します。

1. **追加チケットの購入**
   * アプリ内から「追加翻訳チケット（例：10万文字 / 300円）」をその場で都度購入し、上限枠を即時回復させます。ヘビーユーザーから追加料金をいただくことで、ご主人様の利益になります。
2. **自己所有の無料APIキーへの自動切り替え**
   * 事前にユーザーが自分の「DeepL API Free（月50万文字まで無料）」などのキーを登録していれば、上限超過時に自動でそちらに切り替わって動作を継続します。ご主人様に追加のAPIコストは一切発生しません。

これにより、たまに長時間配信を行うユーザーの利便性を損なうことなく、ご主人様側は完全ノーリスクで月額サービスを運営可能になります。
