# FFXI用語・装備名自動検証スキル

このスキルは、執筆中のマークダウン記事内に含まれるFF11の装備名、アビリティ名、魔法名などが実在する正しい名称であるかを自動検証し、憶測による架空の装備名の記述を防ぐための手順を定義します。

## 使用方法

記事の変更（replace_file_contentやwrite_to_fileなど）を行う直前、またはコミット（git commit）を行う直前に、必ず検証スクリプト「scripts/validate_terms.py」を実行して、編集対象のマークダウンファイルを検証します。

## 検証ルール

1. 対象マークダウンファイルから、装備リストや解説文に含まれる「装備名」「アビリティ名」を抽出します。
2. 抽出した単語が、自動リンク辞書「link_map.js」に登録されている、または登録済みのパターン（例：ニャメで始まる単語など）に該当するか確認します。
3. 登録されていない新規の装備名等については、検証スクリプトを実行して用語辞典のWebサイト（wiki.ffo.jp）へ検証リクエストを送信し、実在するページが存在するか（ステータスが200か）を自動で確認します。
4. 実在しない架空の名称が検出された場合は、処理を中断して直ちに記述を正しい正式名称に修正します。
