# Professional Productivity MCP Collection

## Description
このスキルは、2026年時点で最も信頼性が高く、安全性が確認された「プロフェッショナル向けMCPサーバー群」を統合したものです。特に開発効率の向上とデータの安全な取り扱い（RAG対応、サンドボックス実行）に特化しています。

## Integrated Servers (Safety Verified)
1. **Zapier MCP (Workflow Hub)**: 6,000以上の外部サービスと安全に連携し、定型業務を自動化します。
2. **Chroma/Vectara MCP (Smart Memory)**: 文書を意味的に理解し、正確な情報（RAG）をエージェントに提供します。
3. **Playwright MCP (Browser Automation)**: 隔離されたブラウザ環境でウェブ操作やスクレイピングを実行します。
4. **Filesystem MCP (Local Operations)**: ローカルファイルへのセキュアなアクセスと管理を行います。
5. **Python Sandbox MCP (Safe Execution)**: 任意のコードを隔離されたサンドボックス環境で実行し、メインシステムを保護します。

## Instructions
1. **自動連携の開始**: 外部のデータやツールが必要な際、このコレクションから最適なMCPサーバーを自律的に選択します。
2. **ゼロトラスト検証**: 全ての外部接続に対し、最小権限（Read-only優先）でのアクセスを徹底します。
3. **機密情報の保護**: APIキーや個人情報が含まれる場合、送信前に自動的にマスキングまたは除外します。

## Usage
- 「Zapier経由で、新しいタスクをGoogleカレンダーに登録して」
- 「Playwrightを使って、最新の技術ドキュメントを要約して」
- 「サンドボックス内で、このデータ解析スクリプトを実行して結果を出して」
